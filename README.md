# CampusPrint — student project
You are building a print-shop assistant for a campus business. Today, help the attendant calculate correct prices and serve several customers without restarting the program.

Run `python main.py` from this folder. If necessary use `python3` or `py` instead of `python`. There are no packages to install.

Read `BUSINESS_RULES.md`, complete the TODOs in `main.py`, and work through `ACCEPTANCE.md`. Use only the programming ideas listed in `TASKS.md`. Keep this working folder: future lessons will extend this same application.

Submit `main.py`, a short `reflection.md`, and your completed scenario evidence. Never submit real customer information. All examples use fictional orders.
